# 《为什么你的游戏点子很好，但就是做不出来？》Canva PPT 分镜

用途：给视频口播配套使用的 Canva / PPT 视觉稿。  
参考方向：Isto Inc.《The Game Dev Advice That Took 10 Years to Discover》那种“演示稿 + 图表 + 案例截图 + 少量实机”的风格。  
核心目标：不是做传统讲课 PPT，而是做一套可以直接放进视频剪辑里的视觉资产。

---

## 0. 整体视觉规范

### 画幅

- 推荐：16:9 横屏，1920 × 1080
- Canva 选择：Presentation 16:9

### 风格关键词

- 独立游戏开发
- 深色背景
- 红色警示色
- 灰盒原型感
- 开发债务
- 取舍 / 砍需求
- 演示文稿式视频 essay

### 配色

主背景：
- 深灰黑：`#171717`
- 中性灰：`#2B2B2B`
- 浅灰：`#D9D9D9`

主强调色：
- 警示红：`#E63946`

辅助色：
- 原型蓝：`#5DADE2`
- 完成绿：`#52B788`
- 旧纸黄：`#F2C94C`

使用比例：
- 70% 深灰 / 黑
- 20% 灰白文字和线条
- 10% 红色强调

### 字体建议

Canva 中文标题：
- 思源黑体 Heavy / Noto Sans SC Black
- 阿里巴巴普惠体 Heavy
- 站酷酷黑

Canva 英文标题：
- Anton
- League Spartan
- Bebas Neue

正文：
- 思源黑体 Regular
- Noto Sans SC Regular

### 统一元素

每一页尽量保留这几个元素之一：

- 红色大标题
- 灰色坐标轴 / 箭头
- 手绘风线条
- 图表标签
- “GameBoy小新”小水印
- 章节角标，例如 `01 / 05`

### 动画原则

不要花哨转场。模仿参考视频，主要用：

- Fade 淡入
- Rise 上浮
- Wipe 擦入
- Pop 弹出
- Match Cut / 直接切
- 轻微 Zoom in

## Slide 01｜开场标题

对应口播：
> 为什么你的游戏点子明明很好，但就是做不出来？

画面文案：

主标题：
为什么你的游戏点子很好，  
但就是做不出来？

副标题：
好点子 ≠ 好游戏

视觉设计：

- 深黑背景
- 左侧超大红色标题
- 右侧放一个“未完成游戏工程”的视觉隐喻：
  - 文件夹图标
  - Unity logo 风格方块
  - 报错图标
  - 半透明游戏手柄
- 标题中的“做不出来”用红色，其他用白色

Canva 搜索元素关键词：
- game controller outline
- folder icon
- warning icon
- code window
- pixel game

动画：
- 标题逐行 Fade in
- “好点子 ≠ 好游戏”最后 Pop 出来

## Slide 02｜脑子里的神作

对应口播：
> 我要做一个开放世界加肉鸽。我要做一个魂类加种田……

画面文案：

中间：
我的独立游戏

开放世界  
肉鸽  
魂类  
种田  
多结局  
养成  
战斗  
建造

视觉设计：

- 中间一个红色圆圈写“我的独立游戏”
- 周围不断长出关键词气泡
- 气泡越多，画面越挤
- 最后可以在角落出现小字：
  “想象不需要成本”

Canva 做法：
- 用圆形元素 + 文字
- 关键词气泡做成灰色边框
- 用线条连接中心圆

动画：
- 中心圆先出现
- 气泡一个个 Pop 出来
- 最后画面轻微放大，制造“失控感”

## Slide 05｜主模型：独立游戏执行冰山

# Canva 制作顺序建议

1. 先做 3 页核心模板：
   - 标题页模板
   - 图表页模板
   - 卡片页模板

2. 再做主模型：
   - 独立游戏执行冰山
   - 后续页面反复复用它

3. 最后补素材页：
   - Unity 截图
   - Steam 页面截图
   - Obsidian 文档截图
   - 任务板 / Bug 表截图

4. 全部页面做完后，统一检查：
   - 是否都是深色背景
   - 红色是否只用于重点
   - 每页是否只有一个核心观点
   - 字是否足够大，手机端能看清
   - 有没有太多小字

# 视频剪辑使用方式

建议把 Canva 页面导出为 PNG 或 MP4：

- 静态图表页：导出 PNG
- 有动画的页面：导出 MP4
- 在剪辑软件中按口播节奏插入
- 每页停留 8-25 秒，不要切太快
- 重要金句页可以停留更久

参考节奏：

- 开场 0:00 - 0:40：Slide 01-04
- 创意部分 0:40 - 2:00：Slide 05-07
- 原型部分 2:00 - 3:30：Slide 08-10
- 开发债务 3:30 - 5:30：Slide 11-13
- 砍需求 5:30 - 7:00：Slide 14-15
- 执行判断 7:00 - 8:20：Slide 16-17
- 总结 8:20 - 结尾：Slide 18
