# 项目任务目标
最终想要达到的效果：Night in the Wood, 灵魂摆渡人
两个月（重做+新做），一个月Polish


## 程序任务

### 项目代码完全重构

### 推理系统重新设计

推理变成连线的方式来做推理

### 功能修改：悬疑+ 轻模拟
- 删掉所有小解密
- 模拟和悬疑结合一下
- 家园小物件购买和装修
- 删掉所有的小条件，用非常明确的任务线来引导玩家行为
- 时间系统（白天，下午，黑夜）


# 工作流程

1. 最初的大纲， 然后程序美术策划一起对
2. 中等程度，程序美术策划一起对
3. 最终版非常详细的策划案， 程序美术一起对，精确到组建级别

### 程序工作时长安排
每天早上同步进度，其他时候程序做任务

### 项目进度管理
- 三个月，每个月要有硬性的deadline
- 要有非常详细的策划案，以周为单位来进行迭代，每周更新进度
- 不能存在做完一个功能然后重新推翻，做之前要完全想清楚，策划根据case验收
